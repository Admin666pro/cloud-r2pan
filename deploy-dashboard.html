Crystal Drive · Cloudflare 图形化部署

全程在 dash.cloudflare.com 浏览器控制台完成，无需命令行。
只需创建资源 → 接入代码 → 绑定 → 填密钥，4 步上线。
绑定：BUCKET(R2) · DB(D1) · ADMIN_KEY(Secret) · Worker: crystal-drive
📌
说明：本页是「控制台图形化（GUI）」流程，适合在线操作与新人上手。 命令行 CLI / GitHub Actions 的自动化流程 已保留在项目 README 中，未做改动，本页只是多提供一条可视化路径。
1

🌐 登录 Cloudflare 控制台

打开 dash.cloudflare.com 并登录你的账户。首次使用需先完成账户注册与邮箱验证。

访问 https://dash.cloudflare.com
2

🗄️ 创建 D1 数据库 数据表

左侧栏进入 Workers & Pages → 找到 D1，点击 Create database。

  • 数据库名称：crystal-drive
  • 创建后点进数据库，复制显示的 database_id，稍后用
绑定名 DB · 资源名 crystal-drive · database_id xxxxxxxx-…
建表(info/shares 等)由代码首次请求自动完成，控制台无需手动建表。
3

📦 创建 R2 存储桶 文件存储

左侧栏进入 R2 Object Storage → 点击 Create bucket。

  • 桶名称：crystal-drive（与 D1 同名即可，二者互不影响）
  • 区域保留默认 Automatic，创建完成
绑定名 BUCKET · 桶名 crystal-drive
4

⚙️ 创建 Worker 运行代码

进入 Workers & Pages → 点 Create → 选择 Create Worker。

  • Worker 名称：crystal-drive
  • 先点 Deploy 建立空 Worker（代码下一步接入）
Worker 名称 crystal-drive · 入口 src/index.ts
5

🔧 接入项目代码 最重要的一步

本项目为 TypeScript 多文件（含 HTML 文本模块），控制台在线编辑器无法直接编译，需按下列方式之一接入代码：

方式 A · Git 集成（推荐）：在 Create 时选「Upload via Git / 连接到 GitHub」，选择仓库 Admin666pro/cloud-r2pan，Cloudflare 会根据 wrangler.jsonc 自动构建并部署。
方式 B · 本地编译后上传：在本机 npm install 后执行 npx wrangler deploy，代码已上传到该 Worker（本页仅展示控制台图形入口）。
⚠️ 无论哪种方式，都需要先把 database_id 填进 wrangler.jsonc（占位符 LOCAL_PLACEHOLDER），否则部署会失败。
6

🔗 绑定 D1 与 R2 Binding

进入 Worker crystal-drive → Settings → Bindings → Add：

  • Add D1 Database：变量名 DB，选择数据库 crystal-drive
  • Add R2 Bucket：变量名 BUCKET，选择桶 crystal-drive
DB → crystal-drive（D1）｜BUCKET → crystal-drive（R2）
7

🔐 设置管理密钥 ADMIN_KEY Variable / Secret

进入 Settings → Variables and Secrets → Add，类型选 Secret：

  • 变量名：ADMIN_KEY
  • 值：自定义的一串登录密钥（勿与代码库中的开发密钥相同）
ADMIN_KEY（Secret）
⚠️ 该密钥即管理后台登录口令，请妥善保管；对应本地开发使用的 .dev.vars 里的 ADMIN_KEY。
8

🚀 部署完成，开始使用

返回 Workers 列表，打开 crystal-drive，访问管理后台：

https://crystal-drive.<你的账户>.workers.dev/admin

用 ADMIN_KEY 登录，即可上传文件并生成分享链接。

✅ 部署完成
https://crystal-drive.<你的账户>.workers.dev/admin
